1. Чем `List<T>` отличается от массива?

Массив имеет фиксированный размер, а List<T> может динамически увеличивать и уменьшать количество элементов.

2. Какой способ доступа используется для элемента `List<T>` и что означает `Count`?

Для доступа к элементу используется индекс в квадратных скобках  Count показывает количество элементов в списке

3. Для какой задачи удобен `Dictionary<TKey,TValue>`?

Dictionary удобен для хранения пар «ключ — значение» и поиска значения по ключу, например названия товара и его цены

4. Чем `TryGetValue` полезнее прямого обращения `dictionary[key]` при поиске?

TryGetValue позволяет проверить наличие ключа и получить значение, не вызывая исключение, если ключ отсутствует.

5. Для чего нужен `HashSet<T>` и почему в нём не появляются дубликаты?

HashSet нужен для хранения уникальных элементов. Повторяющиеся значения не добавляются, поскольку коллекция автоматически обеспечивает уникальность элементов

6. Почему для списка товаров, телефонного справочника и набора уникальных тегов подходят разные коллекции?

List удобен для хранения последовательности товаров, Dictionary — для связи имени с номером телефона, а HashSet — для хранения уникальных тегов без повторений

7. Представьте задачу «имя студента → его средний балл». Почему здесь удобнее `Dictionary`, чем `List`?

Dictionary удобнее, потому что позволяет быстро найти средний балл по имени студента. Имя выступает ключом, а средний балл — значением.
